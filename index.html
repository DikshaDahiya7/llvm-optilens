● UNOPTIMIZED INTERMEDIATE CODE (-O0)

Direct Syntax-Driven Code Generation

1. Stack Memory Allocation (alloca) Every declared variable reserves memory on the stack RAM. Each access requires explicit read/write (load/store) instructions.
2. Runtime Loop & Arithmetic Execution Arithmetic operations and loop branch evaluations are deferred entirely to CPU runtime execution.
3. Retained Dead Code Unreferenced and unused variables remain in the generated intermediate code, consuming registers and binary size.
● OPTIMIZED INTERMEDIATE CODE (-O2)

Target-Independent Optimization Passes

1. Register Promotion & Zero Stack Access Stack allocations are eliminated. Function parameters and computed values are mapped directly to hardware registers.
2. Constant Folding & Loop Unrolling Deterministic loops and known constant calculations are evaluated at compile-time, replacing complex blocks with a single static constant.
3. Dead Code Elimination (DCE) Unreachable instructions and unused variables that do not affect the program output are permanently discarded.
